
# Serial Port HMI Command Set

Note:

1. The device command terminator is the three bytes: `0XFF 0XFF 0XFF` (HEX data, not string data).

2. All command names and parameters are ASCII string data, not HEX data, for easy reading and debugging.

3. All command names use lowercase letters (this only applies to command names; parameters should still be uppercase when necessary).
